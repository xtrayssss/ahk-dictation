# 🎙️ AHK Dictation

[English](README-EN.md) · [Русский](README.md)

Лёгкая диктовка голосом для Windows 10: жмёшь горячую клавишу, говоришь, а текст печатается туда, где стоит курсор — в терминал, браузер или любой редактор.

Ничего тяжёлого в памяти не висит: распознавание идёт в облаке (Groq / Whisper).

## Как это работает

```
Ctrl+Alt+D  →  ffmpeg пишет WAV с микрофона
Ctrl+Alt+D  →  отправка в Groq Whisper → текст вставляется в фокус
```

- **Стек:** AutoHotkey v2 (хоткей, ~5–10 МБ в памяти) + ffmpeg (dshow, 16 кГц mono WAV) + встроенный `curl.exe`.
- **Никакого Python и SDK** — принципиально.
- Хоткей задан по скан-коду (`^!SC020::`), поэтому работает в любой раскладке.
- Поддержка зашита на Whisper v3, специально под смешанную русско-техническую речь.

## Требования

- Windows 10, AutoHotkey **v2**.
- [`ffmpeg.exe`](https://www.gyan.dev/ffmpeg/builds/) (в скрипте прописан путь из сборки yt-dlp).
- Ключ Groq API.

## Установка

1. Положи рядом со скриптом файл `openai_key.txt` с ключом (формат — `gsk_...`):
   ```
   gsk_your_key_here
   ```
   Можно взять `openai_key.txt.example` как шаблон. Файл с ключом добавлен в `.gitignore`.
2. Проверь строку `MIC` — подставь точное имя своего микрофона. Список устройств:
   ```bat
   ffmpeg -hide_banner -list_devices true -f dshow -i dummy
   ```
3. Запусти:
   ```bat
   AutoHotkey64.exe dictate.ahk
   ```

## Использование

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+D` | первое нажатие — запись, второе — стоп и расшифровка |
| (запись) | в конце текст автоматически печатается в активное окно |

Остановка записи делается через настоящее `Ctrl+C` консоли (`GenerateConsoleCtrlEvent`), чтобы ffmpeg корректно дописал заголовок WAV — битый файл не уйдёт в API.

## Настройки (верх скрипта)

| Переменная | Что делает |
|---|---|
| `MIC` | имя микрофона для dshow (`audio="..."`) |
| `FFMPEG` | путь к `ffmpeg.exe` |
| Whisper-модель | `whisper-large-v3-turbo` (быстрее) — в строке `curl`; можно сменить на `whisper-large-v3` |
| `prompt=...` | подсказка Whisper с техническими терминами (Claude Code, git, Python, API, GitHub) |
